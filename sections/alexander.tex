\section{Alexander}
Collaborative academic writing requires coherent citation practices across all contributing authors.
In APA 7, parenthetical citations place the authors and year inside parentheses \parencite{smith2023}.
When citing specific pages or sections, provide the page locator directly in the bracket argument \parencite[p.~46]{smith2023}.
Multiple sources supporting a single claim can be grouped within one command and are automatically alphabetized \parencite{eiben2015, smith2023}.

\subsection{Citation Strategies in APA 7}
Narrative citations integrate the author directly into the sentence flow, with only the publication year enclosed in parentheses.
As \textcite{miller2021} demonstrated, structured documentation significantly lowers technical barriers for new collaborators.
When referencing foundational models, early seminal papers can be cited narratively alongside algorithmic descriptions \parencite{kennedy1995}.

\subsection{Git Workflow and Conflict Prevention}
Git tracks changes line by line rather than word by word.
Writing in a semantic line break style—placing exactly one sentence per line—isolates modifications to specific diffs.
This strategy enables teammates to edit adjacent sentences without generating false merge conflicts.
